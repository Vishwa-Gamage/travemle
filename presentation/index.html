Introduction & Problem Statement

🗂️

Fragmented Platforms

Travellers must use multiple apps — booking, maps, reviews — leading to disjointed itineraries.

⏳

Time-Consuming Planning

Manual research across TripAdvisor, Google Travel, etc. is inefficient and overwhelming.

🎯

Lack of Personalisation

Existing platforms give generic suggestions, not tailored to individual budgets or interests.

⚡

No Real-Time Adaptation

Current tools cannot dynamically adjust plans for weather changes or local conditions.

✈️
TRAVEMLE solves these by combining AI-powered itinerary generation, user preference learning, and real-time weather integration into a single seamless mobile application.

  • OpenWeather API real-time forecast
  • Rate limiting: login 5/min, plan 10/hr
  • Google Maps multi-waypoint URL export

  • Structured JSON output with budget breakdown
  • Interest-based destination pre-filtering
  • Transport constraint enforcement
🔒

Security & Infrastructure

  • Environment-variable driven configuration
  • Automatic JWT refresh on 401 (silent re-auth)
  • Input validation on all API endpoints
  • CORS configuration, no secrets in source
